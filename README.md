# 🌐 Computer Networks Visual Lab

An interactive web-based project to visualize core **Computer Networks concepts** using animations and simulations.

This project is designed to help students and beginners understand how network communication works behind the scenes.

---

## 🚀 Live Demo

🌐 **Website:** https://cn-visual-lab.vercel.app/

---

## 📖 Project Overview

Computer Networks Visual Lab is an educational web application that demonstrates how common networking processes work through interactive visualizations. Instead of reading lengthy theoretical explanations, users can watch networking concepts unfold step-by-step through animations.

The project covers essential networking topics such as **DNS Resolution**, **HTTP Request Flow**, **TCP 3-Way Handshake**, and **HTTP Status Codes**, making learning both engaging and intuitive.

---

## ✨ Features

- 📡 **HTTP Request Flow Visualization**
  - Understand how a browser communicates with a web server.
  - Follow the complete request–response lifecycle.

- 🌍 **DNS Resolution Simulation**
  - Learn how domain names are translated into IP addresses.
  - Visualize each step involved in DNS lookup.

- 🤝 **TCP 3-Way Handshake**
  - Interactive visualization of:
    - SYN
    - SYN-ACK
    - ACK
  - Understand how reliable TCP connections are established.

- 📊 **HTTP Status Code Explorer**
  - Learn common HTTP response codes:
    - ✅ 200 OK
    - 🔀 301 Redirect
    - ❌ 404 Not Found
    - 💥 500 Internal Server Error

- 🎨 Smooth animations for better visualization.
- 📱 Responsive design for desktop and mobile devices.
